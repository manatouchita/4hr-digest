# ダイジェスト見どころ抽出アプリ

編集者が**完成版のHR動画**を1本アップロードすると、予告編に使う見どころ候補の
CSVが出る。編集者はそのCSVの時刻を見て切り抜く。CSVのDriveへの格納は手動。

## 起動

```
node digest_app/app.js        # → http://localhost:3100
```

初回起動時だけ管理者アカウントが自動作成され、パスワードが**コンソールに1回だけ**
表示される。控え忘れた場合は `digest_app/data/users.json` を消して再起動する
（実行履歴は消えない）。

必要なもの:

- `ffmpeg` / `ffprobe`（PATH上）
- `python3` と `anthropic` パッケージ
- プロジェクト直下の `.env` に `OPENAI_API_KEY` と `ANTHROPIC_API_KEY`

本番（Render）へ上げる手順は `../4HR-digest-deploy/DEPLOY.md`。
コードを直したら `bash digest_app/sync-deploy.sh` で写してからpushする。

## 画面

| パス | 内容 |
|------|------|
| `/` | 動画をアップロードして抽出。自分の実行履歴とCSVダウンロード |
| `/admin` | アカウント発行・停止、全員の実行履歴と概算費用（管理者のみ） |

アカウントは管理者が発行する。自己登録の導線は無い。発行時の初期パスワードは
その場で一度しか表示されない。停止したアカウントはログイン中でも次のアクセスで
締め出される（実行履歴を残すため削除はしない）。

## 処理の中身

`tools/digest_poc.py` をそのまま呼んでいる。CLIとWebでロジックを二重に持つと
挙動がずれるため、Web側は入出力の受け渡しに徹している。

```
アップロード → 音声抽出(ffmpeg) → 文字起こし(OpenAI Whisper API)
→ 見どころ選定(Claude) → 時刻の検証・補正 → CSV / md / json
```

- 実行は同時1本。2本目以降は待機列に入る
- 処理時間の目安は 30分の動画で2分程度、費用は1本あたり30〜50円
- 元動画は処理が終わった時点で削除する（数百MBが溜まらないように）
- CSVとmdは数KBのテキストなので、ファイルではなく実行履歴の中に本文ごと持つ。
  こうしておくと、サーバのディスクが消えても過去のCSVを落とし直せる

## 状態の保存先

`SUPABASE_URL` と `SUPABASE_SERVICE_KEY` があればSupabase、無ければ
`digest_app/data/` のJSONファイル（開発用）。切り替えは `store.js` が吸収する。

保存するのはアカウント・実行履歴・CSV本文だけで、全部あわせて数百KB。
動画と中間ファイルは `DIGEST_WORK_DIR`（既定 `digest_app/data/`）に置く使い捨てで、
起動のたびに空にする。この非対称のおかげで、永続ディスクの無い無料プランでも動く。

| 環境変数 | 用途 |
|----------|------|
| `SUPABASE_URL` / `SUPABASE_SERVICE_KEY` | 状態の保存先。両方揃ったときだけDBを使う |
| `OPENAI_API_KEY` / `ANTHROPIC_API_KEY` | 文字起こし / 見どころ選定 |
| `SESSION_SECRET` | ログインCookieの署名鍵。未設定ならファイルに生成 |
| `ADMIN_PASSWORD` | 初回起動時の管理者パスワード。未設定ならランダム |
| `DIGEST_WORK_DIR` | 動画と中間ファイルの置き場 |
| `PYTHON` | Pythonの実行パス（既定 `python3`） |

## 制約

- **52分を超える動画は通らない**。文字起こしAPIのアップロード上限（25MB）に
  当たるため。分割処理は未実装。完成版HRは15〜30分の想定なので当面は問題ない
- 同じ動画を再アップロードすると文字起こしからやり直しになる（キャッシュは
  ファイルの更新時刻込みで判定しているため）。費用が二重にかかる
- **抜粋文は自動文字起こしで、固有名詞を中心に誤変換がある**。切り出す位置を
  確かめる目印として使い、内容は必ず映像で確認する

## 本番運用に向けて未対応

- 数百MBのアップロードは回線次第で時間がかかる。ブラウザ内で音声だけ抽出して
  送れば14MB程度に減らせるが、環境差が出やすいので未着手。
  無料プランのメモリ・一時ディスクが足りなかった場合はここに手を入れる
- CSVのDrive自動格納（現状は手で格納する運用）
- 無料プランは15分無操作で停止する。次のアクセスは起動待ちで1分ほどかかり、
  停止時に実行中だったジョブは失われる（起動時にエラーとして回収される）
