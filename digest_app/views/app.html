ダイジェスト見どころ抽出

管理 ログアウト
⚠ 出力される抜粋は自動文字起こしです。固有名詞を中心に誤変換があります（例:「京大」が「兄弟」になる）。 抜粋は「切り出す位置を確かめるための目印」として使い、実際に何と言っているかは必ず映像で確認してください。時刻は音声に合わせてあります。
使い方

このツールは、予告編に入れる「見どころ候補」を探して一覧表にするものです。 動画は作りません。切り出す時刻の当たりを付けるまでが役割で、 実際にどこを使うかを決めるのは編集者です。

1. アップロードする

  1. 完成版（カット済み）のHRを1本置く。編集前の素材ではありません
  2. 音声ファイルでも構いません。使うのは音声だけなので結果は同じで、 アップロードがずっと速く終わります。編集ソフトから音声書き出しができるならそちらを推奨
  3. HRコード（25-UT-ot-01 の形）はファイル名から自動で入ります。 入らなければ手で入れてください。出力ファイルの名前になるので、間違えると格納先を間違えます
  4. 候補の本数は6本のままで構いません。上位2本が採用想定、残りは差し替え用の予備です

2. 待つ

30分のHRで2分ほど。終わるまで画面を閉じないでください。 処理中に閉じると結果を受け取れないことがあります。 しばらく誰も使っていないとサーバが寝ているので、最初の1分ほど反応しないことがあります（故障ではありません）。

3. 一覧表（xlsx）を見る

実行履歴からダウンロードします。1行が1シーン候補です。

区分推奨が上位2本＝採用想定。予備は差し替えを検討する用
IN / OUT切り出す位置。時刻は音声に合わせてあります
尺(秒)20〜35秒が想定。外れているものは警告列に出ます
抜粋自動文字起こしなので誤変換があります（例:「京大」が「兄弟」）。 どこを切るかの目印として使い、何と言っているかは必ず映像で確認してください
テロップ案字幕の下書き。そのまま使う前提ではなく、直して構いません
警告尺が範囲外、時刻を自動補正した、など。目を通してから採否を決めてください

4. 記入してDriveに入れる

色の付いた右側5列（採用 / テロップ確定 / IN修正 / OUT修正 / メモ）が記入欄です。 埋めたらDriveの所定の場所に手で格納してください。 Drive上で右クリック →「アプリで開く」→ Googleスプレッドシート で開けます。

うまくいかないとき

  • 52分を超えるHRは通りません。文字起こし側の上限です
  • 同時に処理できるのは1本。他の人が実行中なら待機列に入ります
  • 同じHRを上げ直すと費用が二重にかかります。やり直す前に、失敗の理由を履歴の「ログを見る」で確認してください
  • 候補が的外れなときは、本数を増やすよりそのまま予備から選ぶほうが早いことが多いです
